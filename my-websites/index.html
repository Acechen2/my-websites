历史小知识

贪吃蛇诞生于1976年，最初叫 Blockade（封锁）。后来诺基亚把它装进手机，成了全世界最经典的小游戏！你父母那代人几乎都玩过 👴

⚙️

游戏原理

一条蛇在屏幕上不断移动，吃掉食物后身体变长。撞到墙壁或自己的身体就游戏结束。目标：尽可能吃更多食物，让蛇变得超长！

创建游戏窗口

⭐ 基础

🧠 知识点：import 导入模块

import 是 Python 中"借用工具"的关键字。

Python 自带很多现成的工具包（叫模块或库），比如：

  • turtle — 海龟绘图库，可以在屏幕上画画（我们的主角！）
  • time — 时间相关功能
  • random — 随机数生成
  • math — 数学计算

格式：import 模块名

🧠 知识点：turtle 海龟绘图库

turtle 是 Python 自带的图形库，名字来源于一只在屏幕上爬行的"海龟"。海龟爬过的地方会留下轨迹，就像画画一样！

常用方法：

Turtle()创建一只新海龟（画笔）
.shape('square')设置形状为方形（用来画蛇身）
.color('颜色')设置颜色
.penup() / .pendown()抬笔（不画线）/ 落笔（画线）
.goto(x, y)移动到指定坐标位置
.stamp()在当前位置盖一个印章（留下印记）
Screensize()设置屏幕大小
.listen()开始监听键盘输入
.mainloop()让窗口保持显示（进入主循环）
代码逐行解释
import turtle 导入 turtle 库，这样我们才能使用画图功能。
👉 类比：就像画画前要先拿出画笔和颜料盒
import time, random 同时导入 time（时间控制）和 random（随机生成食物位置）。
👉 一条 import 可以导入多个模块，用逗号分隔
wn = turtle.Screen() 创建游戏窗口对象，赋值给变量 wn。
👉 类比：就像拿出一张画布/黑板
wn.title('贪吃蛇大作战') 给窗口设置标题文字，显示在窗口顶部标题栏
wn.bgcolor('black') 设置背景色为黑色，这样彩色蛇和食物会更醒目！
wn.setup(width=600, height=600) 设置窗口大小为 600×600 像素的正方形
🎨
生活比喻：创建游戏窗口就像准备一张画板。turtle.Screen() 是拿画板，bgcolor('black') 是把画板涂成黑色底色，setup() 是规定画板的大小。

创建蛇头和食物

⭐⭐ 进阶

🧠 知识点：turtle.Turtle() 创建画笔对象

在 turtle 中，每一个可以移动的元素都是一只"海龟"（Turtle 对象）。

我们需要创建多个 Turtle 对象来代表不同的东西：

  • head → 蛇头（方形，绿色）
  • food → 食物（圆形，红色）

每个对象都可以独立设置形状、颜色、速度等属性。

代码逐行解释
head = turtle.Turtle() 创建一个新的 Turtle 对象，作为蛇头。
👉 类比：就像拿出一支新的画笔专门画蛇头
head.speed(0) 设置速度为 0（最快），因为游戏中蛇需要瞬间移动到新位置。
👉 speed(0)=最快，speed(1)=慢，speed(10)=快但不是最快，speed(3)=正常动画速度
head.shape('square') 将蛇头的形状设置为正方形。其他可选：'circle'(圆)、'triangle'(三角)、'arrow'(箭头)、'turtle'(海龟)
head.color('green') 设置蛇头颜色为绿色 🟩
head.penup() 抬笔！非常重要！蛇移动时不应该画出线条。
👉 如果不抬笔，蛇移动时会留下一道长长的线
head.goto(0, 0) 把蛇头放到坐标原点 (0, 0)，即屏幕正中央
head.direction = 'stop' 给蛇头添加自定义属性 direction，初始值为 'stop'（停止状态）。
👉 这个属性记录蛇当前的移动方向
food = turtle.Turtle() 再创建一个 Turtle 对象作为食物
food.shape('circle') 食物设为圆形 🍎（和蛇头区分开）
food.color('red') 食物设为红色
food.penup() 食物也抬笔（不画线）
food.goto(0, 100) 食物初始放在 (0, 100)，即屏幕上方中间位置
🎭
生活比喻：penup() 就像画画时把笔提起来——你可以移动到任何位置但不会留下痕迹。如果不提笔就移动，就像拿着没盖笔帽的笔到处走，会画得到处都是线！

键盘控制 — 让蛇动起来

⭐⭐ 进阶

🧠 知识点：函数 def 定义

函数（function）是一段可以重复使用的代码块。就像一个"技能按钮"，按下就执行预设的动作。

定义格式：

def 函数名():
    # 要执行的代码
    pass

为什么要用函数？因为蛇需要根据不同按键朝四个方向移动，每个方向都需要一套移动规则。写成函数就可以反复调用了！

代码逐行解释
def go_up(): 定义一个叫 go_up 的函数，控制蛇向上移动
  if head.direction != 'down': 防穿身判断！如果当前正在向下走，就不能直接往上走（否则蛇头会钻进自己的身体里）
    head.direction = 'up' 把方向改为'上'
同理还有三个方向函数： go_down()、go_left()、go_right()，逻辑完全一样，只是方向字符串不同
def move(): 这是最关键的移动函数！根据当前 direction 的值，实际移动蛇头到新位置
  if head.direction == 'up': 判断：如果方向是'上'
    y = head.ycor() 获取蛇头当前的 Y 坐标（ycor = y coordinate 的缩写）
    head.sety(y + 20) 把 Y 坐标加 20（向上移动一格）。每个方块大小是 20×20 像素
下/左/右同理：
向下：y - 20  |  向左：x - 20  |  向右：x + 20
wn.listen() 告诉窗口开始监听（监听）键盘按键事件
wn.onkeypress(go_up, 'Up') 绑定按键：当按下 ↑ 键时，执行 go_up 函数
四个方向键绑定：
'Up' → go_up  |  'Down' → go_down
'Left' → go_left  |  'Right' → go_right
🕹️
生活比喻：方向键绑定就像遥控器的按钮——你按"上"，电视频道往上翻；你按"下"，往下翻。每个按钮对应一个动作。

而防穿身判断就像开车不能突然倒车一样——你往前开着呢，得先停下来才能往后开，不然会出事！😅

5

吃食物 + 身体变长

⭐⭐⭐ 核心

🧠 知识点：列表 list 存储蛇身体

列表（list）是 Python 中存储多个数据的容器。蛇的身体就是一串方块，所以用列表来存储每个身体段的位置。

基本用法：

segments = []           # 创建空列表
segments.append(item)     # 在末尾添加元素
len(segments)             # 获取列表长度（蛇身长度）
for seg in segments:      # 遍历列表中每个元素
代码逐行解释
segments = [] 创建一个空列表，用来存储蛇身体的每一个方块。
👉 初始时蛇只有头没有身体，所以列表为空
# 吃到食物的判断 核心算法！判断蛇头和食物的距离是否小于 20 像素（一个方块的尺寸）
if head.distance(food) < 20: distance() 计算 two 个 turtle 对象之间的距离。小于 20 说明碰到了！🍎
  # 把食物移到随机位置 吃到食物后，要把食物重新放到随机位置
  x = random.randint(-280, 280) 生成 -280 到 280 之间的随机整数作为 X 坐标（留出边距避免贴边）
  y = random.randint(-280, 280) 同样生成随机 Y 坐标
  food.goto(x, y) 把食物移到新的随机位置
  # 添加新的身体段 蛇变长的关键！
  new_segment = turtle.Turtle() 创建一个新的 Turtle 作为新的身体段
  new_segment.shape('square') 也是方形
  new_segment.color('#a0d468') 浅绿色（比蛇头稍浅，看起来有层次感）
  new_segment.penup() 身体段也抬笔不画线
  segments.append(new_segment) 把新身体段加入列表！蛇就变长了 ✨
# 身体跟随移动 蛇身移动的核心逻辑！从最后一段往前，每段都移动到前一段的位置
for index in range(len(segments)-1, 0, -1): 从最后一个身体段倒序遍历到第 1 个（不包括第 0 个）
👉 range(起点, 终点, 步长)：-1 表示倒着数
  x = segments[index-1].xcor() 获取前一段的 X 坐标
  y = segments[index-1].ycor() 获取前一段的 Y 坐标
  segments[index].goto(x, y) 当前段移动到前一段的位置
🤔 为什么倒序？
因为如果正序的话：先移动第一段到原位置，第二段再取第一段位置时就取到了新位置（错误！）。倒序则每段都取的是"还没被移动"的前一段旧位置。
🚂
生活比喻：蛇身体移动就像火车车厢——车头往哪走，后面的每节车厢都跟着前一节走。

倒序遍历就像从最后一节车厢开始调整位置：最后一节去倒数第二节原来的地方，倒数第三节去倒数第四节原来的地方……这样就不会互相踩脚了！

主游戏循环 — 整合所有逻辑

⭐⭐⭐ 核心

🧠 知识点：while 循环 — 游戏的心脏

while 循环是游戏持续运行的引擎！只要条件为 True，循环体内的代码就会一遍又一遍地执行。

游戏循环每帧做的事：

  1. 调用 move() 移动蛇
  2. 检测是否吃到食物
  3. 让身体段跟随移动
  4. 检测是否撞墙
  5. 检测是否撞到自己
  6. 短暂延迟（控制游戏速度）
  7. 更新画面

这些操作以每秒约 10 次的速度不断重复，就形成了流畅的游戏画面！

代码逐行解释
while True: 无限循环——游戏一直运行直到玩家死亡退出。
👉 True 永远是真的，所以这个循环永远不会自动结束
  wn.update() 刷新屏幕画面。每次循环都要刷新一次，才能看到蛇的最新位置
   (上面 Step 4 和 Step 5 的代码放在这里)
  # 检查边界碰撞 判断蛇头是否超出屏幕范围
  if head.xcor() > 290 or ...: 如果 X 或 Y 坐标超过 ±290（窗口半宽/高减去边距），说明撞墙了！
    time.sleep(1) 暂停 1 秒，让玩家看到死亡画面
    head.goto(0, 0) 蛇头回到中心
    head.direction = 'stop' 停止移动
    # 隐藏身体段 把所有身体段藏到屏幕外（重置蛇）
    for segment in segments: 遍历每个身体段
      segment.goto(1000, 1000) 移到屏幕外很远的地方（相当于删除）
    segments.clear() 清空身体列表
  # 检查自身碰撞 判断蛇头有没有撞到自己的身体
  for segment in segments: 遍历每个身体段
    if head.distance(segment) < 20: 如果蛇头和某个身体段的距离小于 20 → 撞到自己了！💀
      # 同样的死亡处理... 和撞墙一样的处理方式
  time.sleep(0.1) 控制游戏速度！暂停 0.1 秒 = 每秒约 10 帧。
👉 数值越小越快，越大越慢。0.08=很快，0.15=较慢
❤️
生活比喻：while 循环就像人的心跳——心脏不停地跳动（循环），每一次跳动都推动血液流动（刷新画面、检测碰撞、移动蛇）。time.sleep(0.1) 就像心跳间隔，控制跳动的快慢！

head.penup()

head.direction = 'stop'

# ---- 3. 创建食物 ----
food = turtle.Turtle()
food.speed(0)
food.shape('circle')
food.color('red')
food.penup()
food.goto(0, 100)

# ---- 4. 蛇身体列表 ----
segments = []

# ---- 5. 分数 ----
score = 0
high_score = 0

# ---- 6. 定义方向控制函数 ----
def go_up():
    if head.direction != 'down':
        head.direction = 'up'

def go_down():
    if head.direction != 'up':
        head.direction = 'down'

def go_left():
    if head.direction != 'right':
        head.direction = 'left'

def go_right():
    if head.direction != 'left':
        head.direction = 'right'

def move():
    if head.direction == 'up':
        y = head.ycor()
        head.sety(y + 20)
    if head.direction == 'down':
        y = head.ycor()
        head.sety(y - 20)
    if head.direction == 'left':
        x = head.xcor()
        head.setx(x - 20)
    if head.direction == 'right':
        x = head.xcor()
        head.setx(x + 20)

# ---- 7. 绑定键盘按键 ----
wn.listen()
wn.onkeypress(go_up, 'Up')
wn.onkeypress(go_down, 'Down')
wn.onkeypress(go_left, 'Left')
wn.onkeypress(go_right, 'Right')

# ---- 8. 主游戏循环 ----
while True:
    wn.update()

    # 检查是否撞墙
    if head.xcor() > 290 or head.xcor() < -290 \
       or head.ycor() > 290 or head.ycor() < -290:
        time.sleep(1)
        head.goto(0, 0)
        head.direction = 'stop'

        for segment in segments:
            segment.goto(1000, 1000)
        segments.clear()

        score = 0

    # 检查是否吃到食物
    if head.distance(food) < 20:
        x = random.randint(-280, 280)
        y = random.randint(-280, 280)
        food.goto(x, y)

        new_segment = turtle.Turtle()
        new_segment.speed(0)
        new_segment.shape('square')
        new_segment.color('#a0d468')
        new_segment.penup()
        segments.append(new_segment)

        score += 10

    # 身体跟随移动（倒序遍历）
    for index in range(len(segments)-1, 0, -1):
        x = segments[index-1].xcor()
        y = segments[index-1].ycor()
        segments[index].goto(x, y)

    if len(segments) > 0:
        x = head.xcor()
        y = head.ycor()
        segments[0].goto(x, y)

    move()

    # 检查自身碰撞
    for segment in segments:
        if head.distance(segment) < 20:
            time.sleep(1)
            head.goto(0, 0)
            head.direction = 'stop'

            for segment in segments:
                segment.goto(1000, 1000)
            segments.clear()

            score = 0

    time.sleep(0.1)
