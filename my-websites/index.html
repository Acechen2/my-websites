2.3 Turtle() — 创建游戏角色

turtle.Turtle() 用来创建一个"角色"（小海龟），它可以在画布上移动和绘图。

生活比喻：Turtle就像画笔，Screen就像画纸。你拿着画笔在纸上画。

🌍 坐标系比喻

goto(100, 0) = 从中间向右走100步
goto(0, -100) = 从中间向下走100步

def 是 define（定义）的缩写，用来创建函数。函数就是一段可以重复使用的代码。

❌ 错误写法

✅ 正确写法

def go_up():
    head.setheading(90) # 缩进4空格

4.1 distance() — 碰撞检测

head.distance(food) 计算蛇头到食物的距离。当距离很近时，就认为"吃到"了。

生活比喻：就像你和朋友的距离——如果小于1米，就算"碰到了"
if head.distance(food) < 20: → 蛇头距食物不到20像素，就算吃到了

为什么是20？因为蛇头方块大小是20×20像素，食物也是20像素，所以距离小于20就算重叠。

蛇身怎么实现？每帧把蛇头当前位置添加到列表，然后用for循环画出所有身体段。如果没吃到食物，就删除列表最旧的坐标（保持长度不变）。

4.4 range倒序遍历 — 移动蛇身

蛇身的移动原理：每节身体跟随前一节的位置。

必须倒序遍历！从最后一节开始，每节移到前一节的位置：
for i in range(len(segments)-1, 0, -1):
    x = segments[i-1].xcor()
    y = segments[i-1].ycor()
    segments[i].goto(x, y)

生活比喻：就像排队——前面的人走了，后面的人依次往前挪一位。必须从队尾开始挪，否则位置会乱！

A. head.touch(food)
B. head.distance(food)
C. head.hit(food)
D. head.check(food)
答案：B。distance()计算两个角色之间的像素距离，小于20就算碰到。

2. 为什么蛇身移动要倒序遍历？

A. 正序倒序都一样
B. 倒序运行更快
C. 正序会导致位置覆盖，后面的身体段找不到前一节的原始位置
D. Python只支持倒序遍历
答案：C。正序时，第1节先移到蛇头位置，第2节再移到第1节的新位置（而不是原始位置），位置就全乱了。
