🐍 什么是贪吃蛇？

认识我们的主角——一条永远吃不饱的小蛇

📜

历史小知识

贪吃蛇游戏最早出现在 1976年 的街机游戏中。后来在诺基亚手机上大火——你爸妈那个年代的人应该都玩过！它是最经典的游戏之一。

🧠

核心原理

其实贪吃蛇的逻辑超级简单：

  1. 蛇一直往一个方向走（自动移动）
  2. 玩家控制方向（上下左右）
  3. 吃到食物 → 身体变长 + 得分
  4. 撞墙或撞自己 → 游戏结束
🐍

为什么用 Python？

Python 是最适合新手的编程语言！代码简洁易读，而且我们用到的 turtle 库是 Python 自带的，不用安装任何东西 就能画图和做动画！

Step 3

🐍 创建蛇头和食物

现在我们来画出游戏的主角——小蛇的头，还有它的美食——苹果 🍎

代码：

# ========== 第3部分：创建蛇头 ==========
head = turtle.Turtle()     # 创建一个小海龟（就是蛇头）
head.shape("square")       # 形状：正方形
head.color("#00FF00")      # 颜色：绿色
head.penup()               # 抬起笔（移动时不画线）
head.goto(0, 0)            # 初始位置：画面中央
head.direction = "stop"    # 初始方向：停止不动

# ========== 第4部分：创建食物 ==========
food = turtle.Turtle()     # 创建另一个小海龟（当食物）
food.shape("circle")       # 形状：圆形（像苹果）
food.color("red")          # 颜色：红色
food.penup()               # 抬起笔
food.goto(0, 100)          # 初始位置：稍微偏上一点

🔍 关键概念解释：

Turtle 海龟绘图

Python 内置的画图模块，想象一只小海龟在屏幕上爬，爬过的轨迹就形成图形。我们用它来画蛇头、蛇身、食物等所有元素。

shape() 形状

"square" 正方形（蛇）、"circle" 圆形（苹果）、"triangle" 三角形等，turtle 提供多种预设形状。

penup() 抬笔

penup() = 抬起画笔，移动不留痕迹；pendown() = 放下画笔，移动时画线。

goto(x,y) 坐标定位

屏幕是一个坐标系，中心点 (0,0)，往右 x 增加、往上 y 增加。goto(0,0) 就是去画面正中间。

Step 4

🏃 让蛇动起来 —— 键盘控制和移动

这是最关键的一步！我们要实现两个功能：
① 键盘按方向键能改变蛇的方向   ② 蛇会自动往前走

代码：

# ========== 第5部分：定义方向控制函数 ==========
def go_up():
    if head.direction != "down":  # 不能直接掉头！
        head.direction = "up"

def go_down():
    if head.direction != "up":
        head.direction = "down"

def go_left():
    if head.direction != "right":
        head.direction = "left"

def go_right():
    if head.direction != "left":
        head.direction = "right"

# 绑定键盘按键
window.listen()                          # 开始监听键盘
window.onkeypress(go_up, "Up")           # ↑键 -> 往上
window.onkeypress(go_down, "Down")       # ↓键 -> 往下
window.onkeypress(go_left, "Left")       # ←键 -> 往左
window.onkeypress(go_right, "Right")     # →键 -> 往右

# ========== 第6部分：让蛇真正移动 ==========
def move():
    if head.direction == "up":         # 如果方向是上
        y = head.ycor()                # 获取当前y坐标
        head.sety(y + 20)              # y+20 = 向上移动20像素
    
    if head.direction == "down":       # 如果方向是下
        y = head.ycor()
        head.sety(y - 20)              # y-20 = 向下移动
    
    if head.direction == "left":       # 如果方向是左
        x = head.xcor()
        head.setx(x - 20)              # x-20 = 向左移动
    
    if head.direction == "right":      # 如果方向是右
        x = head.xcor()
        head.setx(x + 20)              # x+20 = 向右移动

🔍 重点理解：

⚠️ 为什么不能直接掉头？

注意看每个方向函数里的 if head.direction != "xxx" 这个判断。如果蛇正在往下走，你不能直接按上键让它往上走（那样等于撞自己了！）。这个判断就是防止"180度掉头"的bug。

💡 移动的原理

每次调用 move() 函数，蛇头就在当前方向上前进 20像素。我们通过循环不断调用 move()，蛇看起来就是在连续移动了。

Step 5

🍎 吃食物 + 身体变长

蛇吃到苹果要变长，还要在新的随机位置生成下一个苹果！

代码：

# ========== 第7部分：蛇身数据 ==========
segments = []    # 用列表存储蛇的身体每一节
score = 0        # 当前分数

# ========== 第8部分：碰撞检测函数 ==========
# 检测是否吃到食物
if head.distance(food) < 20:    # 如果蛇头和食物距离小于20像素
    # 移动食物到随机位置
    x = random.randint(-280, 280)
    y = random.randint(-280, 280)
    food.goto(x, y)
    
    # 增加一节身体
    new_segment = turtle.Turtle()
    new_segment.shape("square")
    new_segment.color("#32CD32")   # 浅绿色（比头稍浅）
    new_segment.penup()
    segments.append(new_segment)   # 加入身体列表
    
    # 加分！
    score += 10
    print(f"当前分数: {score}")

# ========== 第9部分：身体跟随移动 ==========
# 新增的身体节要跟着前面的节走
for index in range(len(segments) - 1, 0, -1):
    x = segments[index-1].xcor()
    y = segments[index-1].ycor()
    segments[index].goto(x, y)

# 第一节身体跟着头走
if len(segments) > 0:
    x = head.xcor()
    y = head.ycor()
    segments[0].goto(x, y)

🔍 核心逻辑拆解：

1 distance() 测距离 — turtle内置方法，算两个对象之间的距离。<20说明碰到了
→
2 random.randint() 随机位置 — 在 -280~280 之间随机取值，保证食物不会跑到外面
→
3 segments 列表存身体 — 每吃一个食物，往列表里加一节
→
4 倒序跟随 — 从尾巴到头，每节都移到前一节的位置（像毛毛虫蠕动）
Step 6

🔄 主游戏循环 —— 把所有内容串起来

最后一步！写一个无限循环，不断执行：移动 → 检测碰撞 → 更新身体 → 刷新画面

代码：

# ========== 第10部分：主游戏循环 ==========
while True:
    window.update()          # 刷新画面（因为tracer(0)关了自动刷新）
    
    # ---- 边界检测：撞墙则游戏结束 ----
    if head.xcor() > 290 or head.xcor() < -290 or \
       head.ycor() > 290 or head.ycor() < -290:
        time.sleep(1)        # 停顿1秒让玩家看清
        head.goto(0, 0)      # 蛇头回中心
        head.direction = "stop"
        
        # 隐藏身体
        for segment in segments:
            segment.goto(1000, 1000)   # 移到屏幕外
        segments.clear()       # 清空身体列表
        
        print("💀 撞墙了！游戏结束！")
    
    # ---- 吃食物检测 ----
    if head.distance(food) < 20:
        x = random.randint(-280, 280)
        y = random.randint(-280, 280)
        food.goto(x, y)
        
        new_segment = turtle.Turtle()
        new_segment.shape("square")
        new_segment.color("#32CD32")
        new_segment.penup()
        segments.append(new_segment)
        
        score += 10
        delay -= 0.001         # 每次吃食物加速一点点！
    
    # ---- 身体跟随 ----
    for index in range(len(segments)-1, 0, -1):
        x = segments[index-1].xcor()
        y = segments[index-1].ycor()
        segments[index].goto(x, y)
    
    if len(segments) > 0:
        x = head.xcor()
        y = head.ycor()
        segments[0].goto(x, y)
    
    # ---- 移动蛇头 ----
    move()
    
    # ---- 检测是否撞到自己 ----
    for segment in segments:
        if segment.distance(head) < 20:
            time.sleep(1)
            head.goto(0, 0)
            head.direction = "stop"
            
            for seg in segments:
                seg.goto(1000, 1000)
            segments.clear()
            print("💀 撞到自己了！游戏结束！")
    
    time.sleep(delay)         # 控制游戏速度（延迟越小越快）
    
    # ---- 显示分数 ----
    print(f"当前分数: {score}")

🎯 主循环流程图：

开始循环
↓
刷新画面
↓
检测撞墙？
是 → 结束重置 否 ↓
检测吃食物？
是 → 加长加分 否 ↓
身体跟随移动
↓
蛇头前进一步
↓
检测撞自己？
是 → 结束重置 否 ↓
暂停一小会儿
↓
回到顶部循环
🧠 关于 while True

while True 表示"永远重复"，这就是游戏的主循环。每循环一次就是游戏的一帧（像电影一样一帧帧播放形成动画）。time.sleep(delay) 控制每帧之间的间隔时间，delay越小游戏越快！

snake_game.py 
"""
=====================================
  🐍 贪吃蛇游戏 - Python完整版
  作者：你的名字
  适合：Python初学者 / 中学生
=====================================
"""

import turtle
import time
import random

# ==================== 初始化设置 ====================
delay = 0.1  # 游戏速度（秒）

# 创建窗口
window = turtle.Screen()
window.title("🐍 贪吃蛇大作战 - Python版")
window.bgcolor("#1a1a2e")
window.setup(width=600, height=600)
window.tracer(0)

# ==================== 创建蛇头 ====================
head = turtle.Turtle()
head.speed(0)
head.shape("square")
head.color("#00ff88")
head.penup()
head.goto(0, 0)
head.direction = "stop"

# ==================== 创建食物 ====================
food = turtle.Turtle()
food.speed(0)
food.shape("circle")
food.color("#ff4757")
food.penup()
food.goto(0, 100)

# ==================== 分数显示 ====================
pen = turtle.Turtle()
pen.speed(0)
pen.shape("square")
pen.color("white")
pen.penup()
pen.hideturtle()
pen.goto(0, 260)
pen.write("分数: 0  最高分: 0", align="center", 
          font=("Courier", 18, "bold"))

# ==================== 蛇身列表 ====================
segments = []
score = 0
high_score = 0

# ==================== 控制函数 ====================
def go_up():
    if head.direction != "down":
        head.direction = "up"

def go_down():
    if head.direction != "up":
        head.direction = "down"

def go_left():
    if head.direction != "right":
        head.direction = "left"

def go_right():
    if head.direction != "left":
        head.direction = "right"

def move():
    if head.direction == "up":
        y = head.ycor()
        head.sety(y + 20)

    if head.direction == "down":
        y = head.ycor()
        head.sety(y - 20)

    if head.direction == "left":
        x = head.xcor()
        head.setx(x - 20)

    if head.direction == "right":
        x = head.xcor()
        head.setx(x + 20)

# ==================== 绑定键盘 ====================
window.listen()
window.onkeypress(go_up, "Up")
window.onkeypress(go_down, "Down")
window.onkeypress(go_left, "Left")
window.onkeypress(go_right, "Right")

# ==================== 主游戏循环 ====================
while True:
    window.update()

    # 边界检测
    if head.xcor() > 290 or head.xcor() < -290 or \
       head.ycor() > 290 or head.ycor() < -290:
        time.sleep(1)
        head.goto(0, 0)
        head.direction = "stop"
        
        for segment in segments:
            segment.goto(1000, 1000)
        segments.clear()
        
        score = 0
        delay = 0.1
        pen.clear()
        pen.write(f"分数: {score}  最高分: {high_score}", 
                  align="center", font=("Courier", 18, "bold"))

    # 吃食物检测
    if head.distance(food) < 20:
        x = random.randint(-280, 280)
        y = random.randint(-280, 280)
        food.goto(x, y)
        
        new_segment = turtle.Turtle()
        new_segment.speed(0)
        new_segment.shape("square")
        new_segment.color("#00cc66")
        new_segment.penup()
        segments.append(new_segment)
        
        delay -= 0.001
        if delay < 0.05:
            delay = 0.05  # 最快速度上限
        
        score += 10
        if score > high_score:
            high_score = score
            
        pen.clear()
        pen.write(f"分数: {score}  最高分: {high_score}", 
                  align="center", font=("Courier", 18, "bold"))

    # 身体移动（从后往前）
    for index in range(len(segments) - 1, 0, -1):
        x = segments[index-1].xcor()
        y = segments[index-1].ycor()
        segments[index].goto(x, y)

    if len(segments) > 0:
        x = head.xcor()
        y = head.ycor()
        segments[0].goto(x, y)

    move()

    # 撞自己检测
    for segment in segments:
        if segment.distance(head) < 20:
            time.sleep(1)
            head.goto(0, 0)
            head.direction = "stop"
            
            for seg in segments:
                seg.goto(1000, 1000)
            segments.clear()
            
            score = 0
            delay = 0.1
            pen.clear()
            pen.write(f"分数: {score}  最高分: {high_score}", 
                      align="center", font=("Courier", 18, "bold"))

    time.sleep(delay)
