🤖 01 Claude Code 是什么？

一句话解释

Claude Code 是 Anthropic 公司推出的终端级 AI 编程助手——在命令行里跟 AI 对话，让它帮你写代码、改 Bug、读项目、操作 Git，就像身边坐了一个高级程序员。

它能做什么？

  • 🧠 理解整个项目 — 自动读取你的代码库，了解上下文
  • ✍️ 写代码 + 改代码 — 告诉它需求，直接生成或修改文件
  • 🐛 找 Bug + 修 Bug — 粘贴报错信息，它帮你定位并修复
  • 📋 操作 Git — 提交代码、创建分支、解决冲突
  • 💻 执行命令 — 运行测试、安装依赖、启动服务
  • 📖 解释代码 — 看不懂的代码丢给它，逐行解释

和 ChatGPT/Copilot 有什么不同？

直接改文件✅ 可以✅ 可以❌ 只能生成
执行命令✅ 可以❌ 不行❌ 不行

📌 WSL 方式功能最完整

WSL（Windows Subsystem for Linux）在 Windows 里运行 Linux 环境，Claude Code 在 Linux 下功能100%可用，适合专业开发者。

1

启用 Windows 功能

按 Windows键 → 搜索 "启用或关闭 Windows 功能" → 勾选：

  • ✅ 适用于 Linux 的 Windows 子系统
  • ✅ 虚拟机平台（Virtual Machine Platform）

点击确定，重启电脑

2

安装 WSL 2 和 Ubuntu

以管理员身份打开 PowerShell，执行：

安装WSLPowerShell
wsl --install

安装完成后设置默认版本为 WSL 2：

设置默认版本PowerShell
wsl --set-default-version 2
3

配置 Ubuntu

从开始菜单启动 Ubuntu，首次启动需要创建用户名和密码。

然后更新系统：

更新系统Bash
sudo apt update && sudo apt upgrade -y
4

在 Ubuntu 中安装 Claude Code

安装 Claude CodeBash
curl -fsSL https://claude.ai/install.sh | bash

⚠️ 不要用 sudo 安装！

使用 sudo 安装会导致权限问题和安全风险。普通用户权限安装即可。

5

验证安装

检查版本Bash
claude --version

💡 WSL 访问 Windows 文件

🔑 05 使用 API Key 登录（国内用户推荐）

如果你在国内无法直接登录 Claude，可以用 API Key 方式接入。
1

获取 API Key

前往 console.anthropic.com 注册并创建 API Key

⚠️ API 是付费的

Anthropic API 按 Token 计费，新账号有 $5 免费额度。使用前请了解计费规则。

2

设置环境变量

在 PowerShell 中执行（将 你的key 替换为实际的 API Key）：

设置API Key（临时）PowerShell
$env:ANTHROPIC_API_KEY="sk-ant-你的key"

如果想永久生效（推荐），用系统环境变量设置：

永久设置（写入系统环境变量）PowerShell
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_API_KEY", "sk-ant-你的key", "User")

设置完后重新打开 PowerShell 终端。

3

直接启动即可

启动PowerShell
claude

设置了 API Key 后，启动时会自动识别，跳过登录流程。

💡 国内网络加速方案

如果你在国内访问 API 不稳定，可以设置代理：

设置代理（临时）PowerShell
$env:HTTPS_PROXY="http://127.0.0.1:7890"

将端口号改成你自己的代理端口。

❓ 08 常见问题 FAQ

安装时提示"无法访问 claude.ai"怎么办？ ▼

这是网络问题，国内访问 Anthropic 服务需要科学上网。解决方案：

  • 使用 VPN/代理后重试
  • 改用 API Key 方式登录（见第05节）
  • 设置代理后安装：$env:HTTPS_PROXY="http://127.0.0.1:7890"
输入 claude 命令提示"不是内部或外部命令"？ ▼

说明环境变量没有生效，尝试以下步骤：

  • 1. 关闭当前终端，重新打开一个新的（最重要！）
  • 2. 如果还不行，重启电脑
  • 3. 检查是否装了多个终端，确保在正确的终端中运行
  • 4. 手动添加 PATH：安装路径通常在 %USERPROFILE%\.claude\bin
Claude Code 免费吗？ ▼

Claude Code 有免费额度，但有限制：

  • 🆓 免费用户：有每日使用额度限制，够日常轻量使用
  • 💰 Claude Pro：$20/月，额度大幅提升
  • 🔑 API Key：按使用量计费，新账号有 $5 免费额度
怎么更新 Claude Code？ ▼

根据安装方式不同：

  • 原生安装器：claude update
  • WinGet：winget upgrade Anthropic.ClaudeCode
  • WSL/Git Bash：curl -fsSL https://claude.ai/install.sh | bash
为什么有些功能用不了？ ▼

运行环境检查命令：

claude doctor

它会告诉你哪些功能可用、哪些缺失。常见问题：

  • Git 未安装 → 安装 Git
  • Node.js 未安装 → 安装 Node.js
  • 非 WSL 环境 → 部分高级 Shell 功能不可用
Claude Code 会自动修改我的代码吗？ ▼

默认情况下，Claude Code 修改文件前会先询问你确认。你可以：

  • 输入 y 确认修改
  • 输入 n 拒绝修改
  • 建议先用 Git 管理项目，这样随时可以回退
PowerShell 执行策略报错怎么办？ ▼

如果提示"无法加载文件，因为在此系统上禁止运行脚本"，执行：

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

输入 Y 确认即可。这是 Windows 的安全策略，允许运行本地脚本。
