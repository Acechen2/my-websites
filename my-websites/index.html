🟣 第2课：Turtle绘图世界
这节课学习Python的绘图库turtle，它能画出贪吃蛇的游戏世界——窗口、蛇头、食物！
2.1 什么是"库"？

📦 库 = 别人写好的工具箱

Python有大量现成的"库"，就像工具箱一样，里面有各种现成的工具可以直接用。
我们做贪吃蛇要用的 turtle库，就是一个专门画图的工具箱。

🎯 生活比喻

想象你要画画：不需要自己造颜料、做画笔，直接买一盒画具就行。import turtle 就是"打开画具箱"的意思。

1import turtle # 导入turtle库，打开画具箱
2.2 创建游戏窗口

🪟 画画首先要有画布

turtle库可以创建一个窗口，这就是我们游戏的"舞台"。

1import turtle 2 3wn = turtle.Screen() # 创建一个窗口对象 4wn.title("贪吃蛇") # 设置窗口标题 5wn.bgcolor("black") # 设置背景颜色为黑色 6wn.setup(600, 600) # 设置窗口大小 600×600 7wn.tracer(0) # 关闭自动刷新（手动控制画面更新）
💡 逐行详解

• turtle.Screen() — 创建窗口，就像搭了一个舞台
• wn.title() — 给舞台挂上名字牌
• wn.bgcolor() — 给舞台刷上背景色
• wn.setup(600, 600) — 舞台宽600像素、高600像素
• wn.tracer(0) — 关闭自动刷新，我们自己决定什么时候更新画面（让游戏更流畅）

2.3 创建Turtle角色 — 蛇头

🐍 蛇头就是一个小方块

turtle库里的"Turtle角色"就像一只小海龟，我们可以控制它的形状、颜色、位置。在贪吃蛇里，蛇头就是一个绿色的方块。

1head = turtle.Turtle() # 创建一个小海龟角色 2head.speed(0) # 最快速度（0=最快） 3head.shape("square") # 形状设为方块 4head.color("green") # 颜色设为绿色 5head.penup() # 抬起画笔（移动时不画线） 6head.goto(0, 0) # 移动到屏幕中心(0,0) 7head.direction = "stop" # 自定义属性：初始方向为停止
💡 关键方法详解

• turtle.Turtle() — 创建一个新的小海龟角色
• .speed(0) — 0表示最快，动画速度共10级(1-10)，0是特殊值=无动画
• .shape("square") — 形状可选："arrow"、"turtle"、"circle"、"square"等
• .penup() — 抬笔！非常重要，不抬笔的话移动会留下痕迹
• .goto(x, y) — 移动到坐标(x, y)，屏幕中心是(0,0)，右正左负，上正下负

🎯 为什么需要penup()？

想象你在纸上用笔画线：落笔时移动会留下线条，抬笔时移动不留痕迹。贪吃蛇的蛇头只需要"瞬移"到新位置，不需要画线，所以必须先抬笔！

2.4 创建食物角色

🍎 食物是一个红色圆形

食物和蛇头的创建方式几乎一样，只是形状改成了圆形，颜色改成了红色。

1import random # 导入随机数库 2 3food = turtle.Turtle() # 创建食物角色 4food.speed(0) # 最快速度 5food.shape("circle") # 形状设为圆形 6food.color("red") # 颜色设为红色 7food.penup() # 抬笔 8food.goto(0, 100) # 食物初始位置在中心上方
💡 坐标系统

turtle使用直角坐标系：
• 中心点是 (0, 0)
• 向右 x 增大，向左 x 减小
• 向上 y 增大，向下 y 减小
• 窗口600×600时，范围大约 x: -300到300，y: -300到300

2.5 Turtle形状和颜色速查
属性可选值用途
shape"arrow" "turtle" "circle" "square" "triangle" "classic"设置角色外形
color"red" "green" "blue" "yellow" "white" 等英文颜色名设置角色颜色
shapesizeshapesize(1, 1) 默认，shapesize(2, 2) 两倍大设置角色大小

🟠 第3课：让蛇动起来
这节课学习函数、列表、键盘事件和循环，让蛇真正能动起来！这是最关键的一课。
3.1 函数 — 可复用的"菜谱"

📝 函数：打包一段代码，随时调用

函数就像菜谱：写一次，做菜时按名字调用就行。不用每次都从头写步骤。

1def say_hello(): # 定义函数：def + 函数名 + 冒号 2 print("你好！") # 函数体：缩进4个空格 3 4say_hello() # 调用函数：函数名 + 括号
💡 函数四要素

1. def 关键字 — 告诉Python"我要定义一个函数"
2. 函数名 — 自己取的名字，最好有含义（如 go_up、move）
3. () 括号 — 可以放参数（后面会学），没有也必须有括号
4. : 冒号 — 冒号下面的缩进代码都属于这个函数

⚠️ 缩进是Python的灵魂

Python用缩进（4个空格）来表示代码归属关系。函数体内的代码必须缩进，否则会报错！这是Python和其他语言最大的区别。

❌ 缩进错误
def go_up():
head.setheading(90)
# 没有缩进！会报错！
✅ 正确缩进
def go_up():
    head.setheading(90)
# 4个空格缩进，正确！
3.2 编写方向控制函数

🎮 上下左右四个方向函数

蛇要能朝四个方向移动，我们需要写4个函数。setheading() 设置蛇头的朝向角度。

1def go_up(): 2 if head.direction != "down": # 如果当前不是向下，才能向上 3 head.direction = "up" # 设置方向为上 4 5def go_down(): 6 if head.direction != "up": # 如果当前不是向上，才能向下 7 head.direction = "down" 8 9def go_left(): 10 if head.direction != "right": # 如果当前不是向右，才能向左 11 head.direction = "left" 12 13def go_right(): 14 if head.direction != "left": # 如果当前不是向左，才能向右 15 head.direction = "right"
💡 为什么要判断"不能反向"？

蛇正在向右走时，不能直接向左——否则蛇头会穿过自己的身体！这是贪吃蛇的经典规则：不能180度掉头，只能90度转弯。

🎯 setheading角度

turtle的方向用角度表示，就像指南针：
• setheading(90) = 向上 ⬆️
• setheading(270) = 向下 ⬇️
• setheading(180) = 向左 ⬅️
• setheading(0) = 向右 ➡️

3.3 列表(list) — 蛇的身体

🐍 蛇的身体是一串方块

贪吃蛇的身体由多个方块组成，随着吃食物越来越长。Python的列表(list)正好能存储多个元素，完美模拟蛇身。

1segments = [] # 空列表，蛇一开始只有头 2 3# 列表的基本操作： 4segments.append("新方块") # 在末尾添加一个元素 5len(segments) # 获取列表长度（元素个数） 6segments[0] # 获取第1个元素（索引从0开始！） 7segments[-1] # 获取最后一个元素
💡 索引从0开始！

Python列表的索引（编号）从0开始：
列表 ["A", "B", "C"] 中：
• [0] = "A"（第1个）
• [1] = "B"（第2个）
• [2] = "C"（第3个）
• [-1] = "C"（最后一个）

3.4 键盘事件监听

🎹 让程序"听"你的按键

turtle可以监听键盘按键，按下某个键时自动调用对应的函数。

1wn.listen() # 开启键盘监听 2wn.onkeypress(go_up, "Up") # 按↑键 → 调用go_up函数 3wn.onkeypress(go_down, "Down") # 按↓键 → 调用go_down函数 4wn.onkeypress(go_left, "Left") # 按←键 → 调用go_left函数 5wn.onkeypress(go_right, "Right") # 按→键 → 调用go_right函数
💡 onkeypress参数详解

wn.onkeypress(函数名, "键名")
• 第1个参数：函数名（不带括号！写 go_up 不是 go_up()）
• 第2个参数：键名（字符串，如 "Up" "Down" "Left" "Right" "w" "a" "s" "d"）

⚠️ 函数名 vs 函数调用

go_up = 函数本身（一个人）
go_up() = 调用函数（让这个人去干活）
在 onkeypress 中写函数名不带括号，因为我们要告诉程序"按这个键时去调用"，而不是现在就调用！

3.5 编写移动函数

🏃 根据方向移动蛇头

蛇头每一步移动20像素（一个方块的大小）：

1def move(): 2 if head.direction == "up": 3 y = head.ycor() # 获取当前y坐标 4 head.sety(y + 20) # y坐标+20，向上移动 5 6 if head.direction == "down": 7 y = head.ycor() 8 head.sety(y - 20) # y坐标-20，向下移动 9 10 if head.direction == "left": 11 x = head.xcor() # 获取当前x坐标 12 head.setx(x - 20) # x坐标-20，向左移动 13 14 if head.direction == "right": 15 x = head.xcor() 16 head.setx(x + 20) # x坐标+20，向右移动
💡 坐标移动逻辑

• 向上：y + 20（y越大越往上）
• 向下：y - 20（y越小越往下）
• 向右：x + 20（x越大越往右）
• 向左：x - 20（x越小越往左）
ycor() 获取y坐标，xcor() 获取x坐标，sety() 设置y坐标，setx() 设置x坐标

3.6 while循环 — 游戏的心跳

🔄 游戏就是不停地重复

贪吃蛇游戏的核心是一个无限循环：每秒重复很多次"移动→检查→更新画面"，就像心跳一样。

1while True: # 无限循环（游戏一直运行） 2 wn.update() # 更新画面 3 move() # 移动蛇 4 time.sleep(0.1) # 暂停0.1秒（控制蛇的速度）
💡 游戏循环三步

1. wn.update() — 刷新画面（因为之前tracer(0)关了自动刷新）
2. move() — 让蛇移动一步
3. time.sleep(0.1) — 暂停0.1秒，控制游戏速度。数字越小蛇越快！

🎯 游戏循环 = 翻书动画

游戏就像翻书动画：每一页（每帧）画面稍有不同，快速翻动（循环）就产生了动的效果。sleep(0.1) 就是每页之间的间隔时间。

4.1 检测吃食物 + 食物随机刷新

🍎 蛇头碰到食物 = 吃到了！

判断蛇头和食物的距离，如果距离小于20像素，就算吃到了。

1if head.distance(food) < 20: # 蛇头和食物距离小于20 2 x = random.randint(-270, 270) # 随机x坐标（-270到270之间） 3 y = random.randint(-270, 270) # 随机y坐标 4 food.goto(x, y) # 食物移到新位置 5 score += 10 # 分数加10 6 # 添加一个新的身体段（下面会讲）
💡 distance()方法

head.distance(food) 计算蛇头和食物之间的直线距离（像素）。为什么用20？因为每个方块是20×20像素，距离20以内就算"碰到了"。

💡 random.randint(a, b)

生成一个 a 到 b 之间的随机整数。食物出现在-270到270之间，因为窗口是600×600，边界大约是±300，留点边距不会贴墙。

4.2 蛇身变长 — 添加新身体段

🐍 每吃一个食物，蛇多一节身体

吃到食物时，创建一个新的方块添加到蛇身体列表中。

1new_segment = turtle.Turtle() # 创建新的身体方块 2new_segment.speed(0) # 最快速度 3new_segment.shape("square") # 方块形状（和蛇头一样） 4new_segment.color("lightgreen") # 浅绿色（和蛇头区分） 5new_segment.penup() # 抬笔 6segments.append(new_segment) # 添加到身体列表
4.3 身体跟随蛇头 — 巧妙的移动逻辑

🤔 蛇身怎么跟着蛇头走？

秘诀：每一节身体移到前一节的位置，从最后一节开始倒序移动！

蛇头先移动 → 最后一节移到倒数第二节位置 → 倒数第二节移到倒数第三节位置 → 第二节移到蛇头旧位置
1# 身体跟随逻辑：从最后一节开始，每节移到前一节的位置 2for i in range(len(segments)-1, 0, -1): 3 x = segments[i-1].xcor() 4 y = segments[i-1].ycor() 5 segments[i].goto(x, y) 6 7# 第0节（紧挨蛇头的那节）移到蛇头的旧位置 8if len(segments) > 0: 9 x = head.xcor() 10 y = head.ycor() 11 segments[0].goto(x, y)
💡 range(len-1, 0, -1) 详解

range(3, 0, -1) 生成序列 [3, 2, 1]：
• 第1个参数：起始值（从最后一节开始）
• 第2个参数：结束值（到1为止，不含0）
• 第3个参数：步长（-1表示倒着数）
这样就能从后往前依次移动每一节身体！

🎯 排队前进

想象一队人手拉手前进：队长（蛇头）先走一步，然后从队尾开始，每个人移到前面那个人的旧位置。如果从队头开始移，所有人的目标位置就都被覆盖了！

4.4 碰撞检测 — 游戏结束条件

💀 碰到边界或自己的身体 = 游戏结束

贪吃蛇有两个死亡条件：

  • 🔴 碰墙 — 蛇头超出窗口边界
  • 🔴 碰自己 — 蛇头碰到身体任何一节
1# 碰墙检测 2if head.xcor() > 290 or head.xcor() < -290 or head.ycor() > 290 or head.ycor() < -290: 3 time.sleep(1) # 暂停1秒 4 head.goto(0, 0) # 蛇头回到中心 5 head.direction = "stop" # 停止移动 6 7# 碰自己检测 8for segment in segments: 9 if segment.distance(head) < 20: # 身体某节和蛇头距离小于20 10 time.sleep(1) # 暂停1秒 11 head.goto(0, 0) # 蛇头回到中心 12 head.direction = "stop" # 停止移动
💡 or 连接多个条件

or 表示"或"，只要其中一个条件成立就执行。碰墙检测4个方向：
• x > 290 — 超出右墙
• x < -290 — 超出左墙
• y > 290 — 超出上墙
• y < -290 — 超出下墙

4.5 分数显示
1pen = turtle.Turtle() # 创建一支"笔"用来写分数 2pen.speed(0) # 最快速度 3pen.shape("square") # 形状（其实看不到，因为隐藏了） 4pen.color("white") # 白色文字 5pen.penup() # 抬笔 6pen.hideturtle() # 隐藏箭头形状（只显示文字） 7pen.goto(0, 260) # 移到屏幕上方 8pen.write("得分: 0", align="center", font=("Arial", 24, "normal"))
