CSS 是什么？

Cascading Style Sheets — 层叠样式表

📄 HTML = 骨架

负责网页的结构和内容，就像一个人的骨架，决定有哪些元素、放在哪里。

🎨 CSS = 外貌

负责网页的样式和外观，决定颜色、字体、大小、位置、动画等一切视觉效果。

⚡ JS = 行为

负责网页的交互和动态效果，让页面"活起来"，响应用户操作。

💡
类比理解：如果把网页比作一个人，HTML是骨架，CSS是穿衣打扮，JS是动作行为。同样的骨架，不同的CSS打扮，就是完全不同的网页风格。

📐 CSS 规则基本结构

style.css
/* CSS 规则的基本格式 */
选择器 {
    属性名: 属性值;
    属性名: 属性值;
}

/* 真实例子 */
h1 {
    color: red;
    font-size: 32px;
    text-align: center;
}

p {
    color: #666666;
    line-height: 1.8;
}

CSS 的三种使用方式

内联样式 · 内部样式表 · 外部样式表

方式 写法位置 优先级 适用场景 推荐度
① 内联样式 写在 HTML 标签的 style 属性里 最高 临时修改单个元素 ⭐（不推荐）
② 内部样式表 写在 <style> 标签里（放在 head 中） 中等 单个 HTML 文件 ⭐⭐⭐
③ 外部样式表 单独的 .css 文件，用 link 引入 最低 多页面统一管理 ⭐⭐⭐⭐⭐
三种写法示例
/* ① 内联样式（直接写在标签里）*/
<p style="color: red; font-size: 18px;">
    我是红色文字
</p>

/* ② 内部样式表（在head里写style标签）*/
<head>
  <style>
    p { color: blue; }
  </style>
</head>

/* ③ 外部样式表（推荐！）*/
<head>
  <link rel="stylesheet"
        href="style.css">
</head>
说明

① 内联：只影响这一个元素

② 内部：影响整个页面的同类元素

③ 外部：可以给多个页面共享样式，修改一个CSS文件就能改所有页面！

💡 我们平时做项目都用外部样式表，就像 baidu 项目里的 styles.css 文件。
🎯

CSS 选择器

告诉浏览器：我要给哪些元素添加样式

标签选择器
直接写 HTML 标签名，选中页面所有该标签
p { }   h1 { }   div { }
.类选择器
用 . 开头，选中 class 属性匹配的元素（最常用！）
.box { }   .title { }
#ID选择器
用 # 开头，选中 id 属性匹配的元素（唯一）
#header { }   #nav { }
* 通配符
选中页面所有元素，常用于统一重置样式
* { margin: 0; }
后代选择器
空格隔开，选中某元素内部的后代元素
div p { }   .nav a { }
选择器对比
/* HTML 结构 */
<p>普通段落</p>
<p class="red">红色段落</p>
<p id="big">大字段落</p>

/* CSS 样式 */
p {
    color: #333;          /* 所有p都变深灰 */
}
.red {
    color: red;           /* 只有class=red变红 */
}
#big {
    font-size: 24px;    /* 只有id=big变大 */
}
效果预览

普通段落 — 深灰色

红色段落 — 只有这个是红色

大字段落 — 只有这个变大

✅
最佳实践：给元素添加 class 是最灵活的方式。同一个 class 可以给多个元素用，一个元素也可以有多个 class，比如：<div class="box red big">

CSS 盒模型

网页中每个元素都是一个"盒子"

margin（外边距）
border（边框）
padding（内边距）
content
内容区域

📦 content（内容）

实际显示文字或图片的区域，由 width 和 height 控制。

🔵 padding（内边距）

内容到边框之间的距离，padding: 10px 20px; 上下10，左右20。

🟣 border（边框）

元素周围的边框线。格式：border: 1px solid #333;

🟡 margin（外边距）

元素与外部元素的距离，margin: 0 auto; 可让块级元素水平居中！

盒模型常见写法
.box {
    width: 300px;
    height: 100px;

    /* padding: 上 右 下 左 */
    padding: 10px 20px 10px 20px;
    /* 简写：上下10 左右20 */
    padding: 10px 20px;

    /* border: 宽度 样式 颜色 */
    border: 2px solid #333;
    border-radius: 8px; /* 圆角 */

    /* margin: 外边距 */
    margin: 20px auto; /* 水平居中 */

    /* 防止padding撑大元素 */
    box-sizing: border-box;
}
效果

这个盒子有：

padding: 16px 24px

border: 2px solid

border-radius: 8px

margin: 10px auto（居中）

⚠️
重要！建议在所有 CSS 开头写：* { box-sizing: border-box; }，这样 padding 和 border 不会撑大元素，布局更好控制。
🖥️

display 属性

控制元素的显示方式

值 描述 典型标签 特点
block 块级元素 div, p, h1-h6, ul 独占一行，可设置宽高
inline 行内元素 span, a, strong, em 不独占行，宽高由内容决定
inline-block 行内块元素 img, input, button 不独占行，但可设置宽高
none 隐藏元素 — 完全隐藏，不占空间
flex 弹性布局 — 强大的现代布局方式（下节详讲）
💡
记忆技巧：div 默认是 block（块），span 默认是 inline（行内）。可以通过 CSS 任意改变，比如让 span 变成 block，让 div 变成 inline-block。
↔️

Flexbox 弹性布局

现代网页布局的主流方式

✅
Flexbox 解决什么问题？传统 CSS 要让元素居中、排成一行、平均分布，代码很复杂。Flexbox 只需几行代码就能搞定！
📐 父容器属性（控制子元素如何排列）
Flex 父容器属性
.container {
    display: flex; /* 开启flex */

    /* 主轴方向 */
    flex-direction: row;     /* 水平（默认）*/
    flex-direction: column;  /* 垂直 */

    /* 主轴对齐（水平方向）*/
    justify-content: center;         /* 居中 */
    justify-content: space-between;  /* 两端对齐 */
    justify-content: space-around;   /* 均匀分布 */

    /* 交叉轴对齐（垂直方向）*/
    align-items: center;     /* 垂直居中 */
    align-items: flex-start; /* 顶部对齐 */

    /* 换行 */
    flex-wrap: wrap; /* 超出换行 */

    /* 间距（现代浏览器支持）*/
    gap: 16px;
}
效果演示

默认排列（row）：

A
B
C

justify-content: space-between：

A
B
C

justify-content: center + gap:

A
B
C
🌟 最实用：水平垂直居中
完美居中
.center-box {
    display: flex;
    justify-content: center; /* 水平居中 */
    align-items: center;    /* 垂直居中 */
    height: 200px;
    background: #f0f0f0;
}

/* 这3行代码是面试常考题！
   以前实现垂直居中很麻烦，
   flex让它变得超简单。*/

实战案例

将所学 CSS 知识应用到真实项目中

案例① 仿百度搜索框（参考你们上学期做的 baidu 项目）
搜索框 CSS
#search-container {
    display: flex;
    width: 580px;
}

#wd {  /* 输入框 */
    flex-grow: 1;
    height: 44px;
    border: 2px solid #4e6ef2;
    border-right: none;
    border-radius: 10px 0 0 10px;
    padding: 0 16px;
    font-size: 16px;
    outline: none;
}

#button {  /* 搜索按钮 */
    width: 108px;
    height: 44px;
    background: #4e6ef2;
    color: white;
    border: none;
    border-radius: 0 10px 10px 0;
    font-size: 15px;
    cursor: pointer;
}
效果
💡
关键技巧：输入框和按钮组合使用 flex，输入框设置 flex-grow: 1 自动填满剩余空间，两者用 border-radius 分别只设置左/右圆角，拼成一个整体。

案例③ 网页顶部导航栏
导航栏 CSS
nav {
    display: flex;
    justify-content: space-between;
    align-items: center;
    background: #1a1a2e;
    padding: 0 40px;
    height: 60px;
}

.logo {
    color: white;
    font-size: 20px;
    font-weight: bold;
}

.nav-links {
    display: flex;
    gap: 24px;
    list-style: none; /* 去掉圆点 */
}

.nav-links a {
    color: #ccc;
    text-decoration: none;
    font-size: 14px;
    transition: color .2s; /* 过渡效果 */
}

.nav-links a:hover {
    color: white; /* 悬停变白 */
}
