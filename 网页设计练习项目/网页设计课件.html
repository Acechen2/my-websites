二、HTML 结构详解

🏗️ 页面整体骨架

一个完整的HTML文档由以下基本结构组成：

<!-- 文档类型声明 -->
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <!-- 头部信息：字符编码、视口、标题、引入CSS -->
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>我的个人主页</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <!-- 页面的所有可见内容都放在这里 -->
    <nav>...导航栏...</nav>
    <section>...内容区块...</section>
    <footer>...页脚...</footer>
</body>
</html>
⚠️ 注意要点：
  • <meta charset="UTF-8"> 声明编码为 UTF-8，确保中文正常显示
  • viewport 元标签是响应式设计的关键，必须加上！
  • <link> 用于引入外部CSS文件

三、HTML 语义化标签

📖 什么是语义化？为什么要用？

语义化就是用最恰当的HTML标签来表达内容的含义，而不仅仅是为了展示效果。

标签 含义 在项目中的用法
<header> 或 <nav> 导航区域 页面顶部的固定导航栏
<section> 独立的章节/区块 每个内容板块（关于我、技能等）
<article> 独立的内容文章 博客文章、新闻条目
<footer> 页脚区域 版权信息、备案号等
<main> 主要内容区 包裹页面的核心内容
<aside> 侧边栏/辅助信息 相关推荐、广告位
💡 语义化的好处：① 让搜索引擎更好地理解你的网页（SEO友好）
   ② 方便屏幕阅读器为视障人士朗读内容
   ③ 代码更易读、易维护

四、核心 CSS 技术详解

🎨 本项目用到的关键CSS技术

基础盒模型 (Box Model)

/* 盒模型 = 内容(content) + 内边距(padding) + 边框(border) + 外边距(margin) */
* {
    box-sizing: border-box;  /* ★★★ 关键设置！让边框和内边距包含在宽高内 */
}

使用 border-box 后，元素的 width 和 height 就包含了 padding 和 border，计算布局时更加方便。

重点Flex 弹性布局

/* Flex 是现代CSS布局的核心技术，非常强大且好用 */
.navbar {
    display: flex;                      /* 开启弹性布局 */
    justify-content: space-between;    /* 子元素两端对齐 */
    align-items: center;              /* 子元素垂直居中 */
}

.about-content {
    display: flex;
    gap: 40px;                        /* 子元素之间的间距 */
}
.about-text { flex: 1.5; }  /* 占1.5份空间 */
.about-card  { flex: 1; }   /* 占1份空间 */

四（续）- 更多 CSS 技术

进阶CSS Grid 网格布局

/* Grid用于二维布局（行+列），适合做卡片网格 */
.skills-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(230px, 1fr));
    /* 解释：每列最小230px，自动适应容器宽度，列数自适应 */
    gap: 25px;              /* 网格间距 */
}

美化渐变背景 & 阴影

/* 渐变背景：linear-gradient(方向, 颜色1, 颜色2, ...) */
.hero {
    background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
}

/* 盒子阴影：x偏移 y偏移 模糊半径 扩散半径 颜色 */
.skill-card {
    box-shadow: 0 3px 15px rgba(0,0,0,0.08);
}

/* 圆角：数值越大越圆 */
.skill-card { border-radius: 12px; }

交互过渡与悬停效果

.btn {
    transition: all 0.3s ease;  /* 所有属性变化都有0.3秒的平滑过渡 */
}
.btn:hover {
    transform: translateY(-3px);  /* 鼠标悬停时向上移动3px */
    box-shadow: 0 8px 25px rgba(0,0,0,0.3);
}

六、表单与动画效果

📝 表单元素的使用

<form action="#" method="post">
    <input type="text" name="name" placeholder="你的名字" required>
    <input type="email" name="email" placeholder="你的邮箱" required>
    <textarea name="message" rows="5" placeholder="想说的话..." required></textarea>
    <button type="submit">发送留言</button>
</form>

🔑 表单重要属性

  • required — 必填项验证
  • placeholder — 占位提示文字
  • type="email" — 自动校验邮箱格式

✨ CSS动画 — 关键帧

/* 定义动画关键帧 */
@keyframes fadeInUp {
    from { opacity:0; transform:translateY(30px); }
    to   { opacity:1; transform:translateY(0); }
}
/* 使用动画 */
h1 { animation: fadeInUp 1s ease; }

七、响应式设计（适配移动端）

📱 什么是响应式设计？

响应式设计的核心理念：同一个网页，在不同设备上都能良好地显示。电脑端看是横排多列，手机端就变成竖排单列。

🔧 实现方法：媒体查询 (Media Query)

/* 当屏幕宽度 ≤ 768px 时（平板及以下），应用以下规则 */
@media (max-width: 768px) {
    
    /* 导航栏改为垂直排列 */
    .navbar {
        flex-direction: column;
        padding: 12px 20px;
    }
    
    /* 多列布局改为单列堆叠 */
    .about-content,
    .contact-content {
        flex-direction: column;
    }
    
    /* Grid改为单列 */
    .skills-grid {
        grid-template-columns: 1fr;
    }
    
    /* 标题字号调小以适应小屏幕 */
    .hero-content h1 { font-size: 32px; }
}
⚠️ 别忘了：做响应式设计前，必须在 <head> 中添加 <meta name="viewport" content="width=device-width, initial-scale=1.0">，否则媒体查询不会生效！
